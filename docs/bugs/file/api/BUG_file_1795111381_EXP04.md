## Steps to Reproduce
1. `GET /api/file?path=/` không kèm token.

## Expected Result
401, giống như các thao tác ghi file.

## Actual Result
200, trả danh sách đầy đủ (tên, đường dẫn, kích thước, thời gian) gồm cả `$avatar-image`, `$book-image`.

## Evidence
```
GET /file (không token)  200 {"list":[{"name":"$avatar-image","path":"/$avatar-image","isFile":false,...},...
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `file-controller.ts`: `GET ""` và `GET /info` khai báo trước `.use(auth)`. Nếu cố ý cho công khai thì đóng bug.
