# [BUG] FILE — Upload và đổi tên file ghi được file ra ngoài thư mục upload (path traversal khi ghi)

## Thông tin chung
- **ID:** BUG_file_1795111378_EXP01
- **Severity:** 🔴 Critical
- **Priority:** P1
- **Nền tảng:** `api`
- **Môi trường:** Local | `http://localhost:4566/api` (Bun 1.4.5 + Elysia, MySQL 8.4.13) | Windows 11 | —
- **Build / Version:** `deploy-vps` @ `5fcd241` (code backend từ `64d41c0`, frontend build từ cùng commit)
- **Test case liên quan:** — (exploratory testing `EXP01`, chưa có bộ TC)
- **REQ ID liên quan:** — (chưa có tài liệu requirements)
- **Test data đã dùng:** `admin@example.com` / `123456`; file `tiny.png` (8 byte)
- **Ngày phát hiện:** 20-11-2026

## Steps to Reproduce
1. `POST /api/file` (multipart) với `files=@tiny.png;type=image/png` và `path=../poc-traversal`.
2. `POST /api/file` với `path=/poc-xss` và filename `../poc-name-traversal.png`.
3. `PUT /api/file/rename` `{"path":"/poc-xss/evil.svg","name":"../../evil2.svg"}`.
4. Kiểm tra thư mục `backend/` trên server.

## Expected Result
Từ chối mọi đường dẫn, tên file hay tên mới thoát ra ngoài thư mục upload (400 "Invalid path"), giống cách `DELETE`, `copy`, `move` đang làm.

## Actual Result
Cả 3 đều thành công. Server tạo `backend/poc-traversal/tiny.png` và `backend/evil2.svg` nằm **ngoài** `backend/upload/`. Bước 2 đưa file lên thư mục cha. (Các file PoC đã được xoá sau khi kiểm tra.)

## Evidence
```
upload path=../poc-traversal  200 {"msg":"Uploaded successfully.","paths":["/..\\poc-traversal\\tiny.png"]}
filename chứa ../             200 {"msg":"Uploaded successfully.","paths":["/poc-name-traversal.png"]}
rename ra ngoài (name=../x)   200 {"msg":"Renamed successfully."}
find: backend/evil2.svg, backend/poc-traversal, backend/upload/poc-name-traversal.png
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `file-controller.ts`: `POST /` dùng `path.join(file_path, p)` và `path.join(pathname, file.name)` mà không gọi `isInside()`. `PUT /rename` chỉ kiểm tra `path` nguồn, không kiểm tra đường dẫn sau khi ghép `name`.
