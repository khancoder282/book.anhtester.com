## Steps to Reproduce
1. `POST /api/file` với file `xss-poc.html` nhưng khai `type=image/png`, `path=/poc-xss`. Kết quả 200.
2. (Tương tự với `evil.svg` có `<script>`, khai `image/svg+xml`.)
3. Ở trình duyệt đang đăng nhập app, mở `http://localhost:4566/view-file/poc-xss/xss-poc.html`.

## Expected Result
Chỉ nhận file ảnh thật (kiểm tra theo nội dung file, không tin Content-Type), không nhận SVG có script. `/view-file` trả kèm `Content-Disposition: attachment` hoặc dùng domain riêng cho file tải lên.

## Actual Result
File được nhận và phục vụ với `Content-Type: text/html` (SVG là `image/svg+xml`). Script chạy trên origin `http://localhost:4566` và đọc được `accessToken` (232 ký tự) trong `localStorage`. Ai mở link (ví dụ ảnh bìa sách hay avatar chia sẻ) đều bị lấy token. (File PoC đã được xoá.)

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** Schema `t.Files({ accept: [...] })` trong `file-controller.ts` chỉ dựa vào MIME do client khai. `/view-file` trả file đúng theo đuôi. Frontend lưu token trong `localStorage` (`frontend/src/api/axios.ts`).
