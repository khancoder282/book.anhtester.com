# [BUG] AUTH — Nhiều lỗi nghiệp vụ trả về 422 "Property 'fields' is missing" thay cho thông báo thật

## Thông tin chung
- **ID:** BUG_auth_1795111368_EXP04
- **Severity:** 🟠 Major
- **Priority:** P2
- **Nền tảng:** `api`
- **Môi trường:** Local | `http://localhost:4566/api` (Bun 1.4.5 + Elysia, MySQL 8.4.13) | Windows 11 | —
- **Build / Version:** `deploy-vps` @ `5fcd241` (code backend từ `64d41c0`, frontend build từ cùng commit)
- **Test case liên quan:** — (exploratory testing `EXP04`, chưa có bộ TC)
- **REQ ID liên quan:** — (chưa có tài liệu requirements)
- **Test data đã dùng:** `t1-empty-pass@test.local`, `t4-long@test.local`, `p1@test.local`
- **Ngày phát hiện:** 20-11-2026

## Steps to Reproduce
1. `POST /api/register` với `password: ""`, **hoặc** `name` dài 300 ký tự.
2. `PATCH /api/profile` với `{"password":"abcdef"}` (thiếu `password_old`), **hoặc** `password_old` sai, **hoặc** `email` trùng với user khác.

## Expected Result
Trả đúng mã lỗi và thông báo do handler viết sẵn, ví dụ 400 "Old password is required when updating password.", "Old password is incorrect.", "Email is already in use.", hoặc lỗi độ dài tên.

## Actual Result
Mọi trường hợp đều trả **422** `{"msg":"Invalid data.","fields":{"fields":["Property 'fields' is missing","Expected object"]}}`. Người dùng không biết mình sai ở đâu.

## Evidence
```
register password rỗng            422 {"msg":"Invalid data.","fields":{"fields":["Property 'fields' is missing","Expected object"]}}
register name 300 ký tự           422 (như trên)
profile đổi pass thiếu password_old 422 (như trên)
profile đổi pass sai password_old   422 (như trên)
profile đổi email trùng user khác   422 (như trên)
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** Handler trả `400 { msg }`, nhưng `response[400]` khai báo `t.Object({ msg, fields })`. Elysia validate response, thấy thiếu `fields` nên ném lỗi `VALIDATION`, và `onError` trong `index.ts` đổi thành 422. Gặp ở `/register` (catch), `/profile` (mọi nhánh 400). Sửa bằng cách bỏ `fields` khỏi schema 400 hoặc trả kèm `fields`.
