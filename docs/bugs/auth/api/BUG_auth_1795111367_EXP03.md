# [BUG] AUTH — Cookie refetchToken có Max-Age ≈ 57 năm thay vì 7 ngày

## Thông tin chung
- **ID:** BUG_auth_1795111367_EXP03
- **Severity:** 🟡 Minor
- **Priority:** P2
- **Nền tảng:** `api`
- **Môi trường:** Local | `http://localhost:4566/api` (Bun 1.4.5 + Elysia, MySQL 8.4.13) | Windows 11 | —
- **Build / Version:** `deploy-vps` @ `5fcd241` (code backend từ `64d41c0`, frontend build từ cùng commit)
- **Test case liên quan:** — (exploratory testing `EXP03`, chưa có bộ TC)
- **REQ ID liên quan:** — (chưa có tài liệu requirements)
- **Test data đã dùng:** `admin@example.com` / `123456`
- **Ngày phát hiện:** 20-11-2026

## Steps to Reproduce
1. `POST /api/login` với tài khoản hợp lệ.
2. Xem header `Set-Cookie: refetchToken=...` của response.

## Expected Result
`Max-Age` tương ứng hạn của refresh token: 7 ngày = `604800`.

## Actual Result
`Max-Age=1795715265` (khoảng 56,9 năm), vì giá trị đã bị gán bằng một mốc thời gian epoch.

## Evidence
```
set-cookie: refetchToken=%24argon2id%24v%3D19...; Max-Age=1795715265; Path=/;
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `auth-controller.ts`: `refetchToken.maxAge = dayjs(userRefreshToken.expiresAt).unix()` đang gán **mốc thời gian** cho `maxAge` (vốn là **số giây còn sống**). Nên dùng `7 * 24 * 3600`.
