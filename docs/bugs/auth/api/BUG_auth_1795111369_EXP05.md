# [BUG] AUTH — Đăng ký, tạo user và sửa profile chấp nhận tên rỗng hoặc chỉ có khoảng trắng; không có độ dài mật khẩu tối thiểu

## Thông tin chung
- **ID:** BUG_auth_1795111369_EXP05
- **Severity:** 🟡 Minor
- **Priority:** P3
- **Nền tảng:** `api`
- **Môi trường:** Local | `http://localhost:4566/api` (Bun 1.4.5 + Elysia, MySQL 8.4.13) | Windows 11 | —
- **Build / Version:** `deploy-vps` @ `5fcd241` (code backend từ `64d41c0`, frontend build từ cùng commit)
- **Test case liên quan:** — (exploratory testing `EXP05`, chưa có bộ TC)
- **REQ ID liên quan:** — (chưa có tài liệu requirements)
- **Test data đã dùng:** `t2-empty-name@test.local`, `t3-space-name@test.local` (password `1`), `c3@test.local`
- **Ngày phát hiện:** 20-11-2026

## Steps to Reproduce
1. `POST /api/register` `{"name":"","email":"t2-empty-name@test.local","password":"123456"}`.
2. `POST /api/register` `{"name":"   ","email":"t3-space-name@test.local","password":"1"}`.
3. `POST /api/user` (có token) `{"name":"","email":"c3@test.local","password":"123456"}`.
4. `PATCH /api/profile` `{"name":""}`.

## Expected Result
Từ chối tên rỗng hoặc chỉ có khoảng trắng (422 kèm `fields.name`). Có quy định độ dài mật khẩu tối thiểu.

## Actual Result
Tất cả đều thành công (201/200). DB có user `name = ''`, `name = '   '`, và mật khẩu `1`.

## Evidence
```
register name rỗng                201 {"msg":"Register successfully."}
register name toàn khoảng trắng  201 {"msg":"Register successfully."}
POST /user name rỗng              201 {"msg":"Created successfully."}
profile name rỗng                 200 {"msg":"Updated profile successfully."}
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** Schema `name: t.String()` không có `minLength` hay `pattern`; `password: t.String()` không có `minLength`. Áp dụng ở `auth-controller.ts` và `user-controller.ts`.
