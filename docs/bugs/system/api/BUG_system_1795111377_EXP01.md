## Steps to Reproduce
1. Gửi `GET http://localhost:4566/view-file/..%2F.env` (không token).
2. Gửi `GET /view-file/..%2Fpackage.json`, `GET /view-file/..%2F..%2F.git%2Fconfig`, `GET /view-file/%2E%2E%2Fsrc%2Findex.ts`.
3. Gửi `GET /view-file/../.env` không chuẩn hoá đường dẫn (`curl --path-as-is`).

## Expected Result
Chỉ phục vụ file nằm trong thư mục upload; đường dẫn có `..` trả 400 hoặc 404.

## Actual Result
Tất cả trả **200 kèm nội dung file**: `backend/.env` (gồm `PORT`, `JWT_SECRET`, `DATABASE_URL`; khi kiểm tra đã che giá trị), `package.json`, `.git/config`, `src/index.ts`. Có `JWT_SECRET` thì ký được token cho bất kỳ user nào.

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `backend/src/index.ts`, route `/view-file/*`: `path.join(cwd, FILEDIR, decodeURIComponent(params['*']))` rồi `fs.existsSync` → `file(p)`, **không** kiểm tra `isInside()` như `file-controller.ts`. Route `/assets/*` có cùng mẫu code nên cũng cần kiểm tra.
