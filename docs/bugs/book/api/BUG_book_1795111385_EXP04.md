## Steps to Reproduce
1. `PATCH /api/book/{id}` với `{"categories":["Novel"], ...}`.
2. `GET /api/book/{id}`.

## Expected Result
Danh sách category được thay bằng `["Novel"]`.

## Actual Result
Thành `["Novel","Testing"]`; không có cách bỏ category hay KM khỏi sách qua API sửa.

## Evidence
```
Sau PATCH category: {...,"categories":["Novel","Testing"],...}
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** PATCH dùng `connectOrCreate` (categories) và `connect` (promotions) mà không có `set: []` trước đó.
