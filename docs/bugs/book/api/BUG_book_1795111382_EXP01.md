## Steps to Reproduce
1. `POST /api/book` `{"name":"Desc Check Book","description":"Original description","status":"UNAVAILABLE","categories":["Testing"],"price":77000}`.
2. `PATCH /api/book/{id}` chỉ với `{"name":"Desc Check Book v2"}`.
3. `GET /api/book/{id}`.

## Expected Result
Chỉ đổi `name`; giá, trạng thái, mô tả, ảnh và category giữ nguyên.

## Actual Result
`price` **77000 → 50000**, `status` **UNAVAILABLE → AVAILABLE**, `description` bị xoá thành `""`, `picture` bị xoá; `currentPrice` vẫn giữ giá trị cũ nên lệch với `price`.

## Evidence

```
PATCH {name}: {"msg":"Book updated successfully."}
Sau PATCH:   {"description":"","price":50000,"currentPrice":84700,"status":"AVAILABLE"}
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `book-controller.ts`: schema `bodyBook` có `default` cho `price` (50_000) và `status` ("AVAILABLE"); PATCH dùng `t.Partial(bodyBook)` nên Elysia điền mặc định. Handler còn gán cứng `description: body.description || ""` và `picture: (body.pictures ?? []).join(",")`. Cùng kiểu lỗi với BUG_user_1795111371_EXP01. UI hiện gửi đủ trường nên ít gặp từ giao diện, nhưng API tài liệu hoá trên Swagger là PATCH (cập nhật một phần).
