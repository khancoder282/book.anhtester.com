## Steps to Reproduce
1. `GET /api/book/{id}` của sách không có ảnh.

## Expected Result
`picture: []`.

## Actual Result
`picture: [{"name":"","path":"","isFile":true,"size":0,"type":"application/octet-stream",...}]`: thư mục gốc upload bị coi là một file ảnh.

## Evidence
```
GET chi tiết sách không có ảnh -> picture  [{"name":"","path":"","isFile":true,"size":0,"type":"application/octet-stream",...}]
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `"".split(",")` trả `[""]`; `path.join(file_path, "")` là thư mục upload (có tồn tại), nên vượt qua `fs.existsSync`. Cần lọc chuỗi rỗng và kiểm tra `isFile()`.
