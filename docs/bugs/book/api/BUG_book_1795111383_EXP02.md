# [BUG] BOOK — Tạo sách không gửi promotions thì mọi khuyến mãi đang hiệu lực đều bị áp vào giá bán

## Thông tin chung
- **ID:** BUG_book_1795111383_EXP02
- **Severity:** 🔴 Critical
- **Priority:** P1
- **Nền tảng:** `api`
- **Môi trường:** Local | `http://localhost:4566/api` (Bun 1.4.5 + Elysia, MySQL 8.4.13) | Windows 11 | —
- **Build / Version:** `deploy-vps` @ `5fcd241` (code backend từ `64d41c0`, frontend build từ cùng commit)
- **Test case liên quan:** — (exploratory testing `EXP02`, chưa có bộ TC)
- **REQ ID liên quan:** — (chưa có tài liệu requirements)
- **Test data đã dùng:** `admin@example.com`; KM đang hiệu lực: `(code rỗng) PERCENTAGE 10`, `PCTNEG PERCENTAGE -20`
- **Ngày phát hiện:** 20-11-2026

## Steps to Reproduce
1. Có ít nhất một khuyến mãi đang hiệu lực (isActive, trong khoảng ngày).
2. `POST /api/book` `{"name":"NoPromo Undefined","categories":["Testing"],"price":100000}` (không có `promotions`).
3. `POST /api/book` cùng body nhưng thêm `"promotions":[]` (tên `NoPromo EmptyArray`).
4. Xem `price`, `currentPrice` và danh sách promotions của hai sách.

## Expected Result
Sách không gắn khuyến mãi thì `currentPrice = price = 100000`.

## Actual Result
Sách không gửi `promotions`: `currentPrice = 110000` dù **0 promotion được gắn**, tức là đã áp cả hai KM đang chạy (+20% −10%). Sách gửi `[]` thì đúng 100000.

## Evidence
```
KM đang hiệu lực: (rỗng) PERCENTAGE 10 | PCTNEG PERCENTAGE -20
NoPromo Undefined    body={}                 price=100000 currentPrice=110000 promotions gắn=0
NoPromo EmptyArray   body={"promotions":[]}  price=100000 currentPrice=100000 promotions gắn=0
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `book-controller.ts` POST: `prisma.promotion.findMany({ where: { isActive: true, id: { in: body.promotions }, ... } })`. Khi `body.promotions` là `undefined`, Prisma **bỏ qua** điều kiện `in`, nên lấy về mọi KM đang hiệu lực.
