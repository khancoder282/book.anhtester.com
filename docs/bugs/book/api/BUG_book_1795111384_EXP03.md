## Steps to Reproduce
1. `PATCH /api/book/{id}` với `{"price":200000, ...các trường còn lại giữ nguyên}`.
2. `GET /api/book/{id}`.

## Expected Result
`currentPrice` được tính lại theo giá mới: 200000 nếu không có KM.

## Actual Result
`price = 200000` nhưng `currentPrice` vẫn là `120000`.

## Evidence
```
Sau PATCH price: {"price":200000,"currentPrice":120000,"status":"UNAVAILABLE",...}
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `book-controller.ts` PATCH: `currentPrice: body.promotions ? handlePrice(...) : undefined`, nên chỉ tính lại khi client gửi `promotions`.
