## Steps to Reproduce
1. `POST /api/book` `{"name":"Đắc Nhân Tâm",...}`, rồi xem `slug`.
2. `POST /api/book` `{"name":"sách kiểm thử một!",...}` khi đã có sách `Sách Kiểm Thử Một`.
3. `POST /api/book` `{"name":"",...}`.

## Expected Result
Slug `dac-nhan-tam`. Lỗi trùng slug báo đúng là trùng slug, hoặc server tự thêm hậu tố. Tên rỗng bị từ chối.

## Actual Result
Slug là `ac-nhan-tam`. Lỗi báo "Book name already exists." dù hai tên khác nhau. Tên rỗng tạo sách với `name = ""`, `slug = ""`, và trên UI link chi tiết là `/book-management/detail/`.

## Evidence
```
slug của 'Đắc Nhân Tâm'   "ac-nhan-tam"
tên khác nhưng slug trùng  400 {"msg":"Book name already exists."}
name rỗng                 200 {"msg":"Book created successfully."}  -> name "", slug ""
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `slugify()` dùng `normalize('NFKD')`, mà `đ`/`Đ` (U+0111/U+0110) không tách dấu được nên bị regex `[^a-z0-9\s-]` xoá; cần `.replace(/đ/gi, 'd')`. Mọi lỗi P2002 đều báo cùng một thông điệp. `name: t.String()` không có `minLength`.
