## Steps to Reproduce
1. Mở `http://localhost:4566/sign-in`, đăng nhập.
2. Xem tab Network.

## Expected Result
Chỉ gọi `GET /api/me`.

## Actual Result
Có thêm request `GET /api/api/me`. Nó trả 200 chỉ vì route catch-all `/*` của backend trả về `index.html`, chứ không phải dữ liệu user.

## Evidence
```
[3628.135] POST http://localhost:4566/api/login → 200 OK
[3628.136] GET  http://localhost:4566/api/api/me → 200 OK
[3628.149] GET  http://localhost:4566/api/me → 200 OK
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** Một chỗ trong luồng sign-in (`frontend/src/pages/sign-in/`) ghép `'/api/me'` với axios đã có `baseURL: '/api'`.
