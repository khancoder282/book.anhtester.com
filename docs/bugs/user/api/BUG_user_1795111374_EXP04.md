# [BUG] USER — User tự khoá được tài khoản của chính mình qua PATCH /api/user/{id}

## Steps to Reproduce
1. Đăng nhập `p3@test.local`.
2. `PATCH /api/user/<id của chính mình>` `{"email":"p3@test.local","isActive":false}`.
3. `GET /api/me` bằng token hiện tại.

## Expected Result
Không cho tự khoá tài khoản đang đăng nhập (400 hoặc 403), hoặc ít nhất phải có bước xác nhận.

## Actual Result
200 "Updated successfully.", sau đó `/me` trả 403 "User account is disabled". User tự khoá mình và không còn cách nào tự mở lại.

## Evidence
```
User tự khoá chính mình  200 {"msg":"Updated successfully."}
Sau khi tự khoá -> /me   403 {"msg":"User account is disabled"}
```

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn
- **Workaround (nếu có):** Không có
- **Nghi ngờ root cause (nếu phân tích được):** `user-controller.ts` PATCH không so sánh `params.id` với `auth.id`.
