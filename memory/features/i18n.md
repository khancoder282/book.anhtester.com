# Đa ngôn ngữ (vi / en)

Thêm 2026-11-20. Code: `frontend/src/locales/`. Không dùng thư viện ngoài (không i18next).

## Cách hoạt động

- `locales/index.ts`: store zustand `useLangStore` (`lang`, `setLang`), hook `useTranslate()` trả `{ t, lang, setLang }`, hàm `translate()` dùng ngoài component.
- Từ điển chia theo namespace, mỗi namespace một cặp file `en/<ns>.ts` + `vi/<ns>.ts`: `common`, `nav`, `auth`, `home`, `book`, `user`, `category`, `promotion`, `file`, `db`, `help`, `components`. Thêm namespace mới thì đăng ký ở cả object `en` và `vi` trong `index.ts`.
- Khoá có kiểu chặt: `TKey` = mọi đường dẫn lá của bản `en` (vd `'book.title'`). Bản `vi` có kiểu `Translation<typeof en>` nên thiếu hoặc thừa khoá là lỗi TypeScript (build fail).
- Tham số: chuỗi `'Xoá "{name}"'` + `t('x', { name })`.
- Ngôn ngữ chọn theo thứ tự: `?lang=vi|en` trên URL → `localStorage['lang']` → mặc định **`en`**. Mặc định `en` để không làm gãy test cũ bám theo chữ tiếng Anh.
- Đổi ngôn ngữ thì đổi luôn `dayjs.locale` (`19 Nov 2026` / `19 Thg 11 2026`), `adapterLocale` của MUI date picker và `<html lang>`.
- Nút chuyển: `layouts/components/language-popover.tsx`, có ở header dashboard và header trang sign-in/sign-up. Locator: `#btn-language`, menu `#menu-language`, mục `[data-lang="vi"]` / `[data-lang="en"]`.

## Quy tắc khi viết code UI

- Mọi chữ hiển thị mới phải qua `t()`. Thêm khoá vào `en/<ns>.ts` trước rồi `vi/<ns>.ts`.
- Component có chữ phải gọi `useTranslate()` để tự vẽ lại khi đổi ngôn ngữ. Không gọi `translate()` ở hằng số cấp module (đóng băng ngôn ngữ lúc import).
- **Không dịch** message trả về từ backend (`res.data.msg`): API vẫn trả tiếng Anh, toast từ backend vì vậy vẫn là tiếng Anh ở cả hai chế độ.
- Giữ nguyên `id`, `name`, `data-*` khi dịch. `aria-label` thì dịch theo ngôn ngữ, nên locator ổn định nên dùng `data-*` (vd màn Category có `data-action="rename|delete"`).

## Tiêu đề tab

- `app.tsx` → `useRouteTitle()`: đặt tiêu đề theo mục menu khớp route bằng `useLayoutEffect`, chạy ngay khi đổi route, trước khi trang lazy tải xong.
- `<Title>` trong trang (`components/title`) dùng `useEffect` và phụ thuộc cả `pathname`, nên luôn chạy sau và ghi đè được tiêu đề chung.
- `index.html` vẫn giữ `<title>` SEO "API RESTful miễn phí…", chỉ thấy trong tích tắc lúc tải trang lần đầu.
