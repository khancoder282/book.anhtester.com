# Giới thiệu Book Anhtester

Ứng dụng quản lý sách dùng để thực hành kiểm thử API, web và mobile.

| Module | Chức năng |
|---|---|
| Book | Thêm, sửa, xoá, tìm kiếm sách |
| User | Quản lý người dùng, khoá/mở khoá tài khoản |
| Promotion | Mã khuyến mãi theo phần trăm, số tiền, miễn phí vận chuyển |
| File | Upload, đổi tên, sao chép, di chuyển, xoá file |
