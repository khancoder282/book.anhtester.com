# book.anhtester.com
Ứng dụng Quản lý sách là web app đơn giản cho phép người dùng thêm, sửa, xóa và tìm kiếm sách. Hệ thống hỗ trợ lưu trữ thông tin như tên sách, tác giả, thể loại, năm xuất bản. Giao diện thân thiện, dễ dùng, phù hợp cho việc học và thực hành thao tác CRUD cơ bản trong phát triển web.
